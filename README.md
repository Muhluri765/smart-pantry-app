Smart pantry manager.

This is an android application that helps users to keep track of all the ingredients inside of their pantry. The application will suggest recipes depending on what ingredients are inside the pantry.

The application is build with java and contains an SQLite database

## How to use pantry manager ##
1. Press "+" button on the bottom right
2.  enter ingredient name, unit type, unit number, category & expiration date
3.  click "save ingredient to save

### Delete ingredient ###
1. go to panyty list
2. press track icon
3. tap "confirm"

## finding suggested recipes ##
1. ensure you have ingredients in the pantry
2. tap the magnifying glass at the top of the screen
3. tap on any recipe you want to try
